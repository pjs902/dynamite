# Design: Orbit Library Sampling — E-jitter for Coverage (A-only)

**Date:** 2026-08-25
**Scope:** Coverage only (`frac_empty_from_library 57.2% → <35%` at fixed `p≈45k`, `r∈[0,1400″]`, `60×61` occupancy). Not anisotropy/Mbh recovery.
**Branch strategy:** isolated `git worktree` (do not disturb `PM_grid` queue until ~02:00 UTC).

## 1. Context & Problem

* Current library: `nE=30,nI2=25,nI3=20,dithering=3 → nrow=15000 → p=45000` (interleaved tube `2norb` + box). `legacy_fortran/iniparam_f.f90:160-162` does `Nener*=dithering` etc., so `begin.dat:1 = 90 75 60`. Sampling is regular in `(E,R,Θ)` — `E` at exact log-spaced shell centres (`logrmin=-2.0, logrmax=3.7`). Measured in `(r,λz)` (`dynamite_analysis/diagnostics.py:orbit_rlz_occupancy`): `57.2%` cells never sampled (white vertical stripes at fixed `r`), `22.3%` sampled-but-zero (black), `20.5%` populated. `47.9%` of reachable cells used.
* Related work: SMART 5D SOS max-distance (Neureiter 2021), FORSTAND random continuous-`E` via Cuddeford β=0 (Vasiliev 2020 §II.4), SchwarMAX fixed `R exp(-R/3.5) exp(-|z|/1.2)` + Jeans `N(vcirc)` — rejected for GC because it injects `vφ≫σ` disk prior and fixed exponential tracer vs King/Wilson MGE.

## 2. Isolation

* **Branch:** `feature/orblib-sampling-jitter` from `diag/alm-observability`.
* **Worktree:** `../dynamite-orblib-jitter` sibling to `../dynamite`. Own `legacy_fortran/orbitstart_jitter` binary (`make orbitstart -j` in worktree). Original `dynamite/legacy_fortran/orbitstart` untouched.
* **Runtime isolation:** `PM_grid` queue keeps `PYTHONPATH=../dynamite`. Jitter tests run with `PYTHONPATH=../dynamite-orblib-jitter` + `config.settings.legacy_settings["directory"]` pointing to jitter binary + fresh `out_jitter/` dirs. `ics_match_settings` hash stays `nE*dithering` on first line, so no cache alias.

## 3. Implementation — E-jitter (point placement, not shell averaging)

**Critical clarification (user §3 feedback):** this controls *where* bundles are placed, not an average over the shell. Each bundle remains a point sample; its 27 dithered sub-orbits stay compact around that point.

* **Config:** `orblib_settings: E_jitter: float 0.0–1.0` (fraction of shell half-width). `0.0` = current exact centres (default, backward compat, bitwise repro). `1.0` = full `Uniform(-ΔE/2,+ΔE/2)` shift.
* **Fortran (`iniparam_f.f90`):** After computing `ener(iE)` on log grid, draw **once per `iE` bundle index** `δE_i ∼ Uniform(-ΔE_{iE}/2,+ΔE_{iE}/2)` via `ran1` seeded from `infil/orbstart.in:1` (`r_seed>0` deterministic, `≤0` stochastic). Set `E_jittered(iE)=E_centre(iE)+δE_i`. Clamp strictly inside shell to avoid ordering inversion. Both `x-z` (tube) and stationary (box) branches share same `E_jittered` array — single draw per `iE`.
* **Dither scatter:** the `27 = d³` sub-orbits already generated by `Nener*=dithering` get additional scatter `±0.1·ΔE/(2·dithering)` around the *jittered centre* (i.e. `≪ shell width`). Bundle stays compact; `qgrid`/`losvd_hist` not smeared across shell. `ΔE` is local shell width `ener(iE+1)-ener(iE)`.
* **Format:** `begin.dat` first line unchanged (`90 75 60`), rest lines are jittered `E` values. `LegacyOrbitLibrary.read_orbit_property_file_base` and `orbit_rlz_from_orbclass` hashing unchanged; only positions of `r` stripes move.

## 4. Evaluation

* **Primary metric:** `orbit_rlz_occupancy(...,rmax=1400″,60×61)` (`dynamite_analysis/diagnostics.py`) → `frac_empty_from_library`. Target `<35%` (from `57.2%`) at same `p`. Secondary: `solver_fill_of_reachable`, `bundles_used 14.5%`, `xrange` sanity (`ΔE` histogram).
* **Procedure:** Build both libraries (`E_jitter=0.0` control vs `1.0`) from same ω Cen `MGE ν*` + `Υ` in isolated `out_jitter/` (worktree binary). Compute `occupancy_tristate_trimmed.png` A/B (white=library gap, black=solver zero, amber `CMAP_ORBIT` `dpi=300`).
* **Tests:** `tests/test_orblib_jitter.py` — (i) `E_jitter=0` bitwise reproduces master `begin.dat` for same seed, (ii) `1.0` stays within shell bounds for 10 seeds, (iii) jittered library has strictly smaller `white%` on ω Cen MGE (property-based).
* **Error handling:** `ics_match_settings` compares `nE*dithering` first line — jitter doesn't change it, so no invalidation. If jitter would invert shell order, clamp. If `ran1` fails, fall back to `E_jitter=0` for that `iE` and log.

## 5. Non-goals / Deferred

* B) FORSTAND-lite `r∼MGE, v∼Cuddeford β=0` random and C) grid rebalance kept as fallback if A stalls `white%` >35% — same worktree, new `sampling: random` flag + Python `begin.dat` writer.
* SCHWARM AX `N(vcirc)` seeding, 5D SOS adaptive near `Mbh`, anisotropy/Mbh mock recovery — out of scope for this branch (coverage-only).

## 6. Risks

* Queue disturbance if original worktree checked out — mitigated by worktree.
* Shell-edge clamping bias — small, measured via `ΔE` histogram.
